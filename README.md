# image-viewer

## If something goes wrong

- **Storage full during import:** the import stops and tells you how many images were saved. Make room, then import again. Images already saved are skipped.
- **An image can't be exported:** the rest still export, and the message names what was left out. The ZIP also lists those images and the reasons in `_not_exported.csv`. `_manifest.csv` lists only the images in the ZIP.
